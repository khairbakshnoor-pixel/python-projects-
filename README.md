# 🐍 Python Projects Collection

A professional collection of my Python projects created during my learning journey as a **BSCS student**. This repository showcases hands-on practice with core Python concepts, logic building, file handling, and mini applications.

---

## 📁 Projects Included

Below is a detailed overview of each project, highlighting its purpose and the Python concepts used.

### 🔢 age_calculator.py

A beginner-friendly program that calculates a user’s age based on their birth year. This project focuses on user input validation, arithmetic calculations, and basic program flow.

### 🏧 atm_project.py

A console-based ATM simulation that allows users to check balance, withdraw money, and deposit funds. It demonstrates conditional statements, loops, and menu-driven programming.

### ➗ calc-by_function.py

A calculator implemented using separate functions for each operation (addition, subtraction, multiplication, division). This project emphasizes modular programming and code reusability.

### 🧮 calculator.py

A simple calculator application built using conditional logic. It helps in understanding decision-making structures and handling user choices.

### 🕒 clock_ON_window.py

A graphical digital clock that displays real-time system time in a window. This project introduces working with time modules and basic GUI-related concepts.

### 📇 contact_app.py

A contact management application that allows users to add, view, and store contact details. It makes use of file handling to save and retrieve data permanently.

### ⏰ digitaltime.py

A lightweight program that shows the current digital time. This project focuses on Python’s date and time handling features.

### 📂 File_create_project.py

Demonstrates creating, writing, and reading files in Python. This project strengthens understanding of file handling operations and data persistence.

### 🎯 guessing_game.py

A fun number guessing game where the user tries to guess a randomly generated number. It uses loops, conditions, and the random module.

### ✊🖐✌ paper_rock_scissor.py

An implementation of the classic Rock-Paper-Scissors game. This project focuses on conditional logic, random choices, and interactive gameplay.

### 🔐 password_Cheker.py

A password strength checker that validates passwords based on length and character rules. It demonstrates string manipulation and logical conditions.

### 🐾 Pet_Game.py

An interactive virtual pet game where users can feed, play with, and manage a pet. The project uses file handling to save progress in `pet_save.txt`.

### 📝 Quiz_game.py

A quiz-based application that asks multiple-choice questions and calculates the final score. It highlights loops, conditions, and user interaction.

### 🏠 Rent_Calculator.py

A practical utility that calculates rent distribution based on user input. This project applies arithmetic operations to real-life scenarios.

### 🍽 RESTURENT_MANAGEMENT.py

A restaurant management system that manages orders and sales records. It uses file handling to store transaction data in `sales_record.txt`.

### 🎓 Student_data.py

A student data management system used to store, view, and manage student records. This project demonstrates structured data handling and file operations.

### ✅ To_DO_List.py

A to-do list application that allows users to add, remove, and view daily tasks. It focuses on list manipulation, loops, and basic CRUD operations.

## 🛠️ Technologies Used

* Python 3
* File Handling
* Functions & Conditional Logic
* Basic Game Logic

## ▶️ How to Run

1. Make sure Python is installed on your system.
2. Clone this repository:

   ```bash
   git clone https://github.com/khairbakshnoor-pixel/python-projects-.git
   ```
3. Navigate to the project folder:

   ```bash
   cd python-projects-
   ```
4. Run any project:

   ```bash
   python filename.py
   ```
